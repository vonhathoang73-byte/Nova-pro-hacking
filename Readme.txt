Как запустить софт ( Для пк . Windows 10 )

1. Качаем python [ https://www.python.org/downloads/ ]

2. В поиск windows пишем cmd ( командная строка )

3. Пишим:

pip install colorama

pip install requests

pip install bs4

pip install random

pip install BeautifulSoup

pip install phonenumbers

pip install pandas

4. Запускаем файл "main.py" с помощью Python.

5. Готово!

Запуск для Termux ( Android )

1. Качаем Termux через google [ К примеру: termux.softonic.ru ]

2. Даем в настройках доступ ко всем файлам 

3. Заходим, пишим:

pkg install python

4. Качаем "Сх проводник" ( можно через PlayMarket )

5. Заходим и ищем скаченный файл ( обезательно формата .zip )

6. Разархивируем 

7. Зажимаем папку с распакованным файлом , копируем путь ( через свойства )

8. Заходим в термукс , пишим : cd (Вставляем путь)

9. python main.py ( Может быть другое название ) [ В случае софта Toolksx пишим python main.py ]

10. Готово!
